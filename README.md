# rust-dll-mcp

MCP server exposing Rust game server DLLs as a searchable knowledge base.

## Install

```bash
# Windows
winget install astral-sh.uv
claude mcp add --scope user rust-dll-mcp -- uvx rust-dll-mcp

# Linux/macOS
curl -LsSf https://astral.sh/uv/install.sh | sh
claude mcp add --scope user rust-dll-mcp -- uvx rust-dll-mcp
```
